# MedGPT-o1 资源与成本分析报告 (Cost & Resource Report)

这份报告详细计算了从数据构造到强化学习训练全生命周期的算力和资金消耗。所有的估算基于工业界标准的 Token 吞吐率和趋动云 (VirtaI Cloud) 40G 单卡算力。

---

## Part A: 0.5B PRM (过程奖励模型) 资源评估

关于是否要亲自训练 0.5B PRM，我们对比了“本地显卡训练”与“纯 API 打分”的两种成本：

### 1. 本地 8G 显卡 (如 RTX 4070/5070 8G) 能否跑通 0.5B PRM 训练？
**结论：完全可以，但必须挂载 LoRA。**
*   **显存账单 (Qwen2.5-0.5B)**：
    *   **全参数微调 (Full-FT)**：模型权重 (1GB) + 梯度 (2GB) + AdamW 优化器状态 (4GB) = 7GB。加上前向传播激活值，8G 显存会**必定 OOM (显存溢出)**。
    *   **LoRA 微调**：冻结 99% 的参数，仅训练注入的 LoRA 层。显存占用将骤降至 **2.5GB ~ 3.5GB**。你的 8G 显存跑 LoRA 绰绰有余，甚至可以把 Batch Size 开到 4 以上。
*   **时间成本**：需要你自己写训练脚本、找数据、调参，大约耗费 **3~5 天** 的工程时间。

### 2. 替代方案：调用 DeepSeek v4 Pro 充当 PRM 裁判
如果我们放弃训练本地 PRM，直接用 DeepSeek API 离线给所有中间路径打分：
*   **假设任务量**：10,000 道题 × 5 条平行路径 = **50,000 条需要打分的轨迹**。
*   **单条 Token 估算**：输入 (问题 + 过程) 约 800 Tokens；输出 (评分 + 简短理由) 约 20 Tokens。
*   **费用计算**：
    *   输入 (未命中缓存)：50,000 × 800 = 40M Tokens × (3元/1M) = **120 元**
    *   输出：50,000 × 20 = 1M Tokens × (6元/1M) = **6 元**
*   **总费用：约 126 元**。
*   **时间成本：只需半天写个并发脚本。**

> [!TIP]
> **战略建议**：如果你的预算充足（不到 200 块钱），强烈建议在数据构造阶段直接用 DeepSeek V4 Pro 替代 0.5B 训练。我们可以在简历上写 **"利用大规模 LLM (DeepSeek-Pro) 离线蒸馏了复杂的 Process Reward，分离出黄金 CoT"**，这样既高端，又省去了 5 天踩坑的痛苦。

## Part B: 全局项目资源与资金消耗预算

下面是涵盖了从零到一训练出一个 MedGPT-o1 的总体成本预算。

### 1. 数据工程 API 调用成本 (DeepSeek v4 Pro)
我们将核心数据管线分为两步：逆向选择题、生成 Complex CoT。

*   **第一步：MCQ-to-OpenQA 逆向重构 (处理 15,000 道选择题)**
    *   输入：15,000 × 300 Token = 4.5M (约 13.5 元)
    *   输出：15,000 × 50 Token = 0.75M (约 4.5 元)
*   **第二步：Complex CoT 生成 (为 10,000 道题每道生成 5 条长轨迹)**
    *   输入：10,000 × 200 Token × 5次 = 10M (约 30 元)
    *   输出：10,000 × 800 Token (长逻辑) × 5次 = 40M (约 **240 元**)
*   **第三步：PRM 离线打分 (见 Part A)**：约 126 元
*   **API 数据构造成本合计**：**约 414 元**。

### 2. 趋动云 (VirtaI Cloud) 算力成本估算
*根据你提供的 P1.medium (通常对标 A100 40G PCIe / A800 40G)，市场标准算力价一般在 **4~5 算力点/小时 (约合 4~5 元/小时)**。*

*   **Stage 1: Complex CoT SFT 训练**
    *   数据量：10,000 条长序列数据 (单条约 1k token)。
    *   在单卡 40G (搭配 DeepSpeed Zero-2 + LoRA) 上跑 2 个 Epoch。
    *   预计时长：**4 ~ 6 小时**。
    *   预计成本：**25 元**。
*   **Stage 2: GRPO / DAPO 在线强化学习**
    *   RL 极其耗时，因为模型需要在线生成 (Generate) 长序列后再评估更新。
    *   预计时长：**20 ~ 24 小时**。
    *   预计成本：**100 ~ 120 元**。
*   **Stage 3: 自动化客观评测 (lm-evaluation-harness)**
    *   跑遍四个数据集 (CMB, CMExam, CMMLU, MedQA)。
    *   预计时长：**3 ~ 4 小时**。
    *   预计成本：**15 元**。
*   **趋动云 GPU 算力成本合计**：**约 160 元** (可预留 200 元应对冗余调参)。
